# Кухонные таймеры: реализованный исходный вариант

Дата: 30.10.2026. Основание — пользовательское ТЗ кухонных таймеров и согласованный
план реализации. Этот документ расширяет продуктовый объём baseline; совместимость
с хостом, владение аппаратурой и ограничения проверки из HOST_COMPAT_CORRECTION
сохраняются. Упоминание LVGL 9 в приложении с эскизами не применяется: целевой UI — 8.4.

Статус: **source/static only; текущая реализация не собрана и не испытана на панели**.
Исторические Build PASS в VALIDATION относятся к более раннему baseline.

## Поведение

- До 20 карточек суммарно в active/saved; следующий новый таймер получает следующий
  цвет #FFB547 → #2DD4BF → #60A5FA → #A78BFA → #F472B6. Освобождение слота цвета других
  карточек не меняет. Начальная форма предлагает 5 минут; нулевой запуск запрещён.
- Длительность: 00:00:01–23:59:59. Имя: до 32 печатных ASCII-символов, допускается
  пустое. No icon/Cup/Pot/Pan/Oven; имя и значок можно удалить через Edit timer.
- Running использует абсолютный monotonic deadline в миллисекундах, paused — точный
  сохранённый остаток. Done отсчитывает время от исходного дедлайна, без знака плюс.
  Остаток округляется вверх до секунд, время после завершения — вниз.
- Добавление времени и Set remaining time меняют только текущий отсчёт. Repeat
  использует сохранённую стартовую длительность; она редактируется в saved.
  Новая дуга после точного задания остатка получает этот остаток как полный диапазон;
  добавление времени расширяет диапазон дуги, если новый остаток его превышает.
- Cancel timer и Acknowledge переводят карточку в начало saved. Start из saved
  добавляет её в конец active и возвращает главный экран. Repeat и дополнительное
  время из done сохраняют позицию active. Remove удаляет только saved.
- При завершении внутри Remaining time барабаны сохраняют выбранные значения,
  Apply становится явным Start timer. Если завершение произошло непосредственно
  перед Apply, первое нажатие только показывает завершение и действие Start timer.
  Открытый редактор имени при завершении закрывается без сохранения черновика.

## UI и жесты

Круги: 280 px при 1–3 карточках, 240 px при 4 и более, 448 px в detail. Три крупные
карточки помещаются без прокрутки: верхние x=32/712, y=8, нижняя x=372, y=168
внутри области y=76…600. Центральная кнопка заканчивается на y=580. Saved timers
закреплена справа: y=542,h=48, отступ справа 20 px, ширина по содержимому. New timer симметрично слева снизу; обе кнопки не перекрывают
центральную карточку. Четыре размещены зигзагом; пять — 3 сверху и 2 в
промежутках снизу. Следующие группы повторяют уменьшенную компоновку вертикально.
Навигация закреплена, scroll active/saved хранится раздельно.

Время использует Inter с весом 750: 72/64/112 px для крупной, уменьшенной и раскрытой
карточек. Для H:MM:SS автоматически выбираются 56/48/72 px, чтобы строка помещалась.
Текст — Inter 20/24 px, заголовки — Inter Bold 32 px. PAUSED/DONE/SAVED расположены
перед именем, как на эскизах. Кнопки компактных карточек — по ширине значка с полями, высота 48 px и минимум 48 px по ширине.
Фон, толщины дуг, панели создания и пиктографический выбор значка приближены к эскизам.
Нулевая длительность и прочие продуктовые правила исходного ТЗ сохраняются.

Кухонные значки — четыре Google Material Symbols Outlined. Управление использует
LV_SYMBOL_* из шрифта, уже поставляемого с LVGL, в локальных размерах 24/32 px; на панели не нужны SVG decoder, FreeType или сеть.
Источники, лицензии и воспроизведение ассетов: components/kitchen_ui/assets/README.md.
Генератор tools/generate_timer_fonts.py запускается отдельно от сборки; он требует
Pillow и официальный исходный Material Symbols TTF. Шрифты не требуют изменения
глобальной конфигурации шрифтов хоста.

Короткое касание круга открывает detail; отдельная кнопка по ширине значка выполняет действие (зона касания минимум 48×48 px).
Удержание 500 мс при движении не более 10 px начинает перенос. Движение до удержания
оставляет жест прокрутке. Предварительный порядок хранится отдельно от модели,
контур обозначает ячейку назначения; отпускание фиксирует порядок, потеря касания
или скрытие UI отменяет перенос. Зоны 40 px у края включают автопрокрутку.

Перемещения, появление/исчезновение и смена размера анимируются за 220 мс.
Перед уходом со списка сохраняется геометрия карточек. Обычная навигация между
списками и возврат из detail не анимируют раскладку. Saved timers при входе всегда
сразу показывает итоговые позиции. Timers анимирует вход только после создания,
запуска saved, отмены или подтверждения из detail, когда меняется состав активных.
Перенос внутри списка и изменения состава уже видимого списка анимируются как прежде. Обычный tick
не пересоздаёт сетку. Все running с остатком больше нуля и не более 60000 мс выделяются внешней
рамкой 6 px с зазором 2 px. Прозрачность мягко меняется от 120 до 255 за цикл
1200 мс, рамка остаётся видимой даже в минимуме. Цвет рамки — назначенный цвет
таймера; порядок и размеры карточек не меняются. Для paused, done и saved
дополнительная пульсация не включается; done сохраняет свой обычный полный контур.
Это правило заменяет выбор одного ближайшего таймера и прежнюю незаметную тень.


## Память, lifecycle и интеграция

Модель фиксированного размера принадлежит app instance. UI хранит указатели только
на собственные дочерние объекты, стабильные ID и ограниченный пул bindings. Все
операции модели/UI сериализованы GUI-lock. Для завершений добавлен отдельный
app-owned LVGL heartbeat 50 мс; standalone-аудио имеет свою задачу и очередь.

LVGL timer с периодом 50 мс действует только при видимом UI. Он актуализирует модель,
обрабатывает жест и обновляет изменившиеся значения/стили. При hide/suspend таймер
приостановлен и анимации отменены. При возврате дедлайны пересчитываются по now_ms:
отсчёт продолжался. Пока LVGL worker обслуживается, app heartbeat фиксирует
завершения и при скрытом UI. Пользовательская Pause
и host pause/suspend — разные операции.

Stop удаляет UI, сохраняя модель до destroy. Внешнее удаление borrowed parent
отменяет собственный timer/animations и очищает ссылки; повторный create_content
создаёт UI той же модели. Destroy и reset теряют все карточки. now_ms должен быть
монотонным и учитывать время скрытия/suspend в пределах живого экземпляра. Deep sleep
с перезагрузкой, восстановление питания, NVS и host notifications не реализуются.
Звук standalone описан ниже; интеграция audio-сервиса хоста остаётся отдельной.

Descriptor по-прежнему can_background=false: модель heartbeat использует живой
LVGL worker, но отдельной поддержки background view/awake хоста нет.
Это не обещание хранения после выгрузки приложения хостом. Полная интеграция с хостом
остаётся отдельной приёмкой; хостовые файлы не изменены. В platform struct
добавлены optional audio callbacks; требуется пересборка зависимых компонентов.

## Standalone-запуск

Приложение открывается на 1024×600 после короткого loading overlay. main больше не вызывает baseline_ui,
не создаёт brightness/diagnostics и тестовые кнопки. Переключения Fixture / Full UI
нет. standalone_runner остаётся минимальным владельцем app instance и borrowed
parent; app_manager ABI fixture по-прежнему нужен только для standalone-компоновки.
Хостовая интеграция и аппаратный display_port не изменены.

В раскрытой карточке геометрия хранится в current_x/current_y/current_size; обновление
времени больше не считывает незавершённый LVGL layout и не записывает нулевой размер
круга обратно. Исправление проверено статически, визуальная приёмка остаётся ручной.

Кухонные значки в редакторе — 48 px, на таймерах — 40 px внутри кружков 64 px.
Для них заново загружены отдельные 40/48-px SVG, цвет задан белый. Stockpot заменил
Cooking в прежнем логическом слоте Pot; сохранённые ID значков модели не менялись.
Растеризация glyphs идёт заново из векторного variable font при нужном optical size,
без увеличения прежних 24/32-px bitmap. Старые кухонные SVG и малые glyphs удалены.

## Крупные 4–5 карточек и спокойный вход в списки (31.10.2026)

Диаметр при 4 и более — 240 px вместо 190 px; время MM:SS — 64 px вместо 48 px,
H:MM:SS — 48 px. При четырёх карточках x=16/264/512/760, y=8/160/8/160;
при пяти верхние x=40/392/744,y=8, нижние x=216/568,y=226. Кнопки и угловые
значки не перекрываются. Последующие группы используют шаг 528 px и прокрутку,
размер больше не уменьшается. Эту же геометрию использует preview при переносе.

Новый одноразовый флаг animate_active_entry отмечает успешные команды, меняющие
состав active. build_list потребляет его: saved всегда без анимации при открытии,
active — с анимацией только после такой команды и при наличии прежней геометрии.
Открытие Saved не воспроизводит закэшированное промежуточное состояние перестроения.

Для пяти карточек нижняя пара начинается на y=226 внутри списка: угловой значок
нижней левой карточки не пересекает верхний центральный круг даже с рамкой.
Высота обёртки равна диаметру +56 px (8 px до кнопки и 48 px сама кнопка), без
лишних 8 px снизу. Последние кнопки заканчиваются на экранном y=598, в пределах
1024×600 без дополнительной прокрутки. Правый нижний круг с рамкой заканчивается
по x на 816, до начала кнопки Saved timers. Шрифт H:MM:SS переключается на 56 px
только при диаметре от 270 px, чтобы строка не обрезалась и во время анимации размера.

## Disabled и пульсирующая тень (31.10.2026, предыдущий вариант)

Недоступные кнопки сохраняют исходный непрозрачный фон, включая оранжевый акцент
и checked-состояние. Серый disabled-фильтр стандартной темы отключён; только текст
и glyphs получают блеклый #7D7D84. Нажатия остаются заблокированы LV_STATE_DISABLED.
Это распространяется и на значки компактных карточек, рисуемые draw callback.

Для RUNNING при остатке ≤60 секунд к рамке добавлена синхронная пульсация тени:
blur 24 px, spread −12…+3 px, opacity 0…200/255, тот же сглаженный период 1200 мс.
Максимальный выход тени наружу — 16 px; рамка в предыдущем варианте пульсировала 120…255/255.
В этом предыдущем варианте новых задач и таймеров не было; тень выключалась
при паузе, завершении и увеличении остатка выше минуты вместе с рамкой.
Текущие параметры и выделение DONE заменены ниже в разделе про chime. Порядок/размеры/цвет карточек не меняются.

Viewport списка расширен вверх: y=64,h=536. Все позиции ячеек относительно него
сдвинуты на +12 px; абсолютные экранные координаты кругов и кнопок сохранены.
Это оставляет место для ореола над первой строкой без обрезания и без перекрытия
заголовка. Например, прежние локальные y=8/160/226 теперь равны 20/172/238.

## Приглушение disabled и подписи формы (31.10.2026)

Disabled сохраняет фон кнопки; текст/значок #7D7D84 дополнительно отображается
с opacity 40%. При восстановлении доступности возвращается обычная непрозрачность.
Поле имени допускает только горизонтальную прокрутку, scrollbar AUTO появляется
при переполнении, а не постоянно и не по вертикали.

Name/Icon и «· optional» создаются двумя обычными labels: название белое, суффикс
светло-серый. Они не проходят через LONG_DOT с ещё не обработанной recolor-разметкой,
поэтому текст заголовка не заменяется многоточием. Положение суффикса определяется
метриками используемого 24-px шрифта, без чтения незавершённого LVGL layout.

## Яркое свечение, громкость и однократный chime (31.10.2026)

Свечение использует opacity, shadow width и spread, как в примере Product Explainer:
ширина размытия 32…56 px, spread −6…10 px, opacity 80…255/255; максимальный выход
наружу 39 px вместо 16 px. Рамка 6 px остаётся заметной (180…255). Списки разрешают
overflow тени, фиксированный непрозрачный header рисуется поверх. Карточки не
меняют размер/порядок. RUNNING ≤60 s и DONE выделены; PAUSED не пульсирует.
DONE сохраняет контур, выделение и отсчёт вверх до Acknowledge, даже после звука.

На Timers справа сверху кнопка громкости с процентом и штатным LV_SYMBOL.
Диалог Volume меняет общий уровень 0…100% сразу, без NVS; default=40%, 0=mute.
New timer — слева снизу с отступом 20 px, Saved timers — справа снизу, обе y=542,h=48.
Никаких разных звуков для карточек и автоматических звуков при открытии меню нет.

Один RUNNING→DONE создаёт одно событие. Повторные update, открытие detail/списка
или возврат из другого экрана не создают его снова. Heartbeat приложения обслуживает
модель/завершения независимо от UI timer, пока живой экземпляр running и LVGL worker
работает. Он сохраняется при hide/suspend/удалении UI, паузится на stop и удаляется
под GUI-lock на destroy. Новых embedded FreeRTOS-задач не добавлено.

События muted завершаются без отложенного воспроизведения при снятии mute.
Несколько одновременных завершений дают отдельные сигналы последовательно.
Очередь standalone ограничена 20 scalar tokens, постановка неблокирующая; переполнение
логируется без повторных попыток и без сброса DONE. Уровень меняется программным
умножением PCM, включая текущий сигнал. Acknowledge не ставит звук на повтор.

Файл main/assets/kitchen_timer_chime.wav — неизменённая копия пользовательского
PCM mono/16-bit/44100 Hz, 68355 samples, 1.55 s, 136754 bytes. SHA-256: 016aeb127f919cf736175d828523e9967c3aea6d23a7877a70906c0e3bbe90a4.
Stereo вывод дублирует mono в оба канала. Короткий буфер 256 frames, без декодера
и без копии всей записи в RAM. Драйвер I2S и задача 4096 bytes stack принадлежат
standalone main до reset; amp GPIO30 active-low, BCLK22/WS21/DOUT23, без MCLK,
как в изученном BSP Product Explainer. I2C/GT911 не переинициализируются.

Hardware sound и плавность усиленного свечения ожидают ручной проверки на текущей
плате; другие HW/silicon профили автоматически не квалифицируются. Хост должен
привязать собственный audio backend; при остановленном LVGL worker точное звуковое
оповещение во сне требует отдельного awake/scheduling контракта хоста.

## Dismiss модальных окон и клавиатуры (31.10.2026)

Edit timer и Volume закрываются касанием затемнённой области вне карточки.
Edit отбрасывает черновик, как Cancel; Volume оставляет уже применённый уровень.
Карточки принимают касания собственного фона, чтобы он не считался backdrop.
Cancel/Save в Edit находятся на y=326,h=48: 16 px до нижнего края карточки.
При клавиатуре Edit поднимается до y=0: кнопки заканчиваются на y=374,
клавиатура начинается на y=380; после скрытия возвращается y=90.

Оба поля имени имеют placeholder “Tap here to name your timer”, серым Inter24.
Это штатный placeholder textarea, не текст/черновик и не часть лимита 32 ASCII.
Касание фона формы или другого активного элемента вне клавиатуры/поля имени
прячет клавиатуру; обычное действие элемента тоже выполняется. Обработчик CLICKED
подключается после action callback, чтобы восстановление геометрии кнопки не
отменяло её нажатие. Клавиши и касания самого поля оставляют клавиатуру открытой.
Callbacks регистрируются один раз при построении формы, удаляются вместе с её
LVGL objects; глобальных input hooks, новых timers и задач нет.

## Speaker-only button и preview громкости (31.10.2026)

На Timers справа сверху только большой штатный LV_SYMBOL_VOLUME_MAX без процентов:
64×48 touch target, существующий default glyph отображается с zoom 2 вокруг центра.
Проценты остаются внутри диалога, крайние значения подписаны 0% и 100%.
LV_EVENT_RELEASED ползунка посылает неблокирующий preview; движение обновляет gain
без запуска звука на каждом шаге. При 0% звук отсутствует.

Используется неизменённый volume_release.pcm из Product Explainer: signed PCM16 LE,
mono 16000 Hz, gain 0.40 относительно выбранного уровня, как в исходном mixer.
Standalone интерполирует его в 44100 Hz stereo короткими блоками в существующей
аудиозадаче. Звук завершения остаётся пользовательским kitchen_timer_chime.wav.
Одновременно допускается один pending/playing preview: быстрые отпускания во время
него объединяются, сигналы завершений не прерываются. Во время chime preview может
ждать в общей очереди. Закрытие диалога не отменяет уже переданный аудиозапрос.

## Мягкая тень без дополнительной рамки (31.10.2026, текущие параметры)

Дополнительный outline отключён. Дуга прогресса остаётся прежней. Для RUNNING ≤60 s
и DONE работает только тень назначенного цвета: постоянный blur 36 px, spread −4…4 px,
opacity 96…208/255, smoothstep с нулевой скоростью в крайних точках, период 1800 ms.
Максимальный выход наружу — 23 px вместо 39; размах расширения уменьшен с 28 до 8 px.
Постоянное размытие также убирает ступеньки изменения blur. PAUSED/SAVED без тени,
порядок/размер карточек не меняется. Это заменяет предыдущие параметры яркого halo.

Громкость нового экземпляра и начальный gain standalone backend — 40%. Последующие
изменения по-прежнему хранятся в RAM до уничтожения экземпляра, без NVS.

## Отзывчивость halo, динамик и повторный preview (текущая правка)

Программный shadow blur LVGL заменён девятью готовыми A8 radial masks, общими для
всех карточек текущей страницы. Период 1800 ms, spread −4…4, opacity 96…208 и цвет
сохранены; профиль размытия аппроксимирован smoothstep. На каждом кадре выбираются
маска и opacity, без native blur и transform layer. Пока размеры меняются в 220-ms
перестроении, halo отсутствует до совпадения с новым размером. Фон карточек за
Edit/Volume заморожен; модель, завершения и звук продолжаются, после закрытия UI
догоняет now_ms. Это снижает перерисовки под полупрозрачным диалогом.

Cache RAM: 736164 bytes для 240 px, 956484 для 280 px, 2196324 для detail 448 px.
Один набор на страницу, без умножения на число карточек. Смена страницы/root delete
инвалидирует LVGL image cache и освобождает память. Если malloc не дал буфер,
используется неподвижная native тень 36 px/152 opacity. Это ограничение fallback,
а не обещание прежней плавности при нехватке RAM.

Speaker button рисует корпус и две волны примитивами LVGL в DRAW_MAIN; текстового
symbol/zoom нет. Preview больше не блокируется флагом pending до конца предыдущего
сигнала. Один gesture (PRESSED → RELEASED либо PRESS_LOST) даёт один запрос; повторный
preview перезапускает текущий на границе блока. Completion chime имеет приоритет.
Очередь ограничена 20 запросами; ошибки постановки логируются, 0% остаётся mute.
