## Время и события

Длительность 1–86399 секунд, ноль только у EMPTY. RUNNING использует абсолютный
монотонный deadline. UI tick не вычитает секунды. Pause/Resume сохраняют дробную
секунду. Остаток округляется вверх, DONE вниз от фактического deadline.
До часа MM:SS, затем H:MM:SS с неограниченным двумя цифрами числом часов; после
суток нет обнуления. Подбирается наибольший существующий шрифт, помещающий строку.

±1 min = ровно ±60000 мс. READY меняет постоянную длительность, RUNNING/PAUSED —
только сеанс с сохранением статуса. Минус недоступен при остатке ≤60000 мс;
плюс недоступен при превышении максимума. Если после вычитания остаётся дробная
секунда, она не округляется до секунды. Точный редактор принимает целые 1–86399 с.
При точном задании остатка span равен новому остатку; при продлении за прежний span
он расширяется. Линейная полоса показывает долю оставшегося времени.
EMPTY/READY/DONE имеют неподвижный пустой трек.

Cancel timer в RUNNING/PAUSED возвращает READY и закрывает overlay к главной сетке. DONE: OK → READY, +1 min → новый
сеанс на 60 секунд, Repeat → новый сеанс на постоянную длительность. Последние
два действия оставляют overlay открытым. Сохранённая длительность не изменяется.

Одно RUNNING→DONE даёт одно событие, которое потребляет существующий audio backend.
Mute не накапливает сигналы для последующего воспроизведения. Очередь standalone,
PCM preview и I2S/PA владение не меняются. С 05.11.2026 сигнал таймера —
пользовательский bell MP3, обрезанный с 4.824 до 2.08 с и преобразованный в WAV
PCM16 mono 44100 Hz. Последние 50 ms плавно затухают; формат/происхождение — SOURCES.md. Ошибки enqueue логируются без retry.

## Развёрнутая карточка и черновики

Одна карточка 600×460, x=212,y=70 (центр экрана), поверх неподвижной затемнённой сетки. Появление
и закрытие мгновенные: без анимации opacity/transform всей панели и без
промежуточного слоя размером с окно.
Касание затемнения закрывает карточку так же, как крестик, с отменой черновика. Крестик отбрасывает
только неподтверждённый редактор. Все уже применённые изменения остаются в RAM
и отправляются в хранилище. Текущий отсчёт при закрытии продолжает работать.

EMPTY: Set up timer, No icon, Add name, нулевые барабаны Hours/Minutes/Seconds, пресеты 1/3/5/10/15/30 min,
единственная Start timer. Пресеты заменяют черновик, не запускают отсчёт. До Start
все параметры локальны; крестик оставляет EMPTY и не создаёт запись слота.
Start применяет черновик, запускает сеанс, отправляет запись и закрывает карточку.

READY: время открывает Duration с шестью пресетами, Cancel/Apply. RUNNING/PAUSED:
Remaining time без пресетов; Apply задаёт остаток относительно нажатия, сохраняя
паузу при PAUSED. DONE: Add more time с начальной минутой, Cancel/Start timer.
Ноль блокирует применение. Барабаны нормальные, без зацикливания через границы.

Таймеры продолжаются при любом редакторе. Завершение не пересоздаёт редактор и
не изменяет барабаны, имя или фокус. Remaining time после DONE показывает Timer
finished и Start timer. Если завершение впервые обнаружено в обработчике Apply,
первое нажатие только меняет действие; запуск требует второго явного нажатия.
Чужой DONE не открывает карточку и не перенаправляет ввод.

Имя открывает английскую QWERTY-клавиатуру. Done применяет имя, кнопка отмены
клавиатуры восстанавливает прежнее. Пустое имя разрешено. Центральные элементы
скрыты, верх и строка полей той же панели остаются на месте (y=70),
а её нижний край поднимается до y=372, над клавиатурой (высота 302 px),
сетка остаётся неподвижной. Клавиатура 1024×220 привязана к BOTTOM_MID без смещения
(y=380 на экране); поле явно получает фокус, default keyboard handler сохранён.
Поле ввода занимает то же место, что имя в обычной строке; Done/Cancel
расположены под ней. Новая modal/panel для имени не создаётся. Режим и значения
барабанов после ввода восстанавливаются. Done не запускает таймер.

Значок открывает строку пяти вариантов целиком, без анимации изменения ширины.
No icon в исходной ячейке и строке выбора расположен под символом Block по центру,
внутри той же ячейки высотой 80 px. Исходный значок и имя временно скрыты: в строке остаются только пять вариантов.
Выбранный вариант имеет акцентно-оранжевый фон. Нажатый вариант — оранжевую
рамку 2px, место для которой зарезервировано в обычном состоянии без сдвига glyph. Первый тап вне строки внутри
overlay только закрывает её; прозрачный input guard перехватывает также жесты
барабанов, не позволяя этому касанию менять черновик под строкой. Выбор применяет значок и сворачивает строку.
Открытие значков отменяет неподтверждённое имя. Имя/значок редактируются и в DONE.

## Подсветка и громкость

Обычная рамка 5 px/220 opacity без внешней тени. RUNNING строго ниже минуты:
ширина рамки плавно меняется 6–9 px, DONE — 7–11 px. Прозрачность пульсирует
100–255, с периодом 2 с / 1,7 с соответственно. Геометрия карточки и текста не
двигается: меняется только рисуемый inset border. Внутреннее свечение приглушено
до 60–72 opacity, ширина 6 px / 8 px. PAUSED не пульсирует, эффект затухает.
Пульсация инвалидирует четыре краевые полосы по 20 px вместо всей карточки.

Под timer/Volume overlay перерисовка фоновых карточек заморожена, кроме изменения
статуса (в частности DONE); heartbeat, deadlines, звук и storage продолжаются.
После закрытия отображение догоняет актуальную модель. Это не остановка таймеров.

Высота progress bar: 16 px на S1–S3 и overlay, 10 px на S4–S5. Кнопки действий
48 px по высоте; зоны касания не уменьшаются ниже 48×48. Все надписи и время
размещены отдельно от прогресса. Новых шрифтов, bitmap-масок и opacity/transform layers карточек нет.
Неактивная Start timer видна с непрозрачной серой заливкой и серым текстом;
активная — акцентно-жёлтая. Клавиши при нажатии окрашиваются в ACCENT, текст в BG.
Крестик имеет область 48×48, отступы от правого/верхнего края 4/2 px.

Volume сохраняет существующие проценты, slider 0–100%, границы, Done и крестик.
Gain меняется сразу; RELEASED/PRESS_LOST дают один preview и один запрос сохранения.
Скрытие/удаление формы заканчивает незавершённый жест без добавочного preview.
Без аудиосервиса кнопка недоступна. Начальная громкость 40%.

## Постоянное хранение

Standalone владеет NVS-адаптером, namespace `kitchen`, ключи `slot1`…`slot5`, `volume`.
Используется существующий NVS partition 0x9000/0x6000; разметка не меняется.

Слот v1: `[version:u8=1][duration_s:u32 little-endian][icon:u8][name_length:u8][ASCII bytes]`.
Длина 7–39 байт, без завершающего NUL. Для EMPTY duration=0, icon=0, name_length=0.
Volume v1: `[version:u8=1][percent:u8]`, ровно 2 байта. Проверяются длина, схема,
диапазоны, значок и ASCII. Никаких дампов C-структур, padding или указателей.

Запись слота: первый Start, Done имени, выбор значка, Apply Duration и прямые ±1 min
в READY. Открытие/отмена редактора не пишет. Громкость записывается при завершении
жеста, не на каждом изменении slider. Неизменившееся подтверждённое значение не пишется.
Deadline, остаток, статусы сеанса, цвет и порядок не записываются никогда.

Один FreeRTOS worker standalone со stack 3072 bytes и семью фиксированными mailbox
копирует snapshot, выполняет nvs_set_blob и nvs_commit последовательно. Последний
не начатый запрос ключа заменяет предыдущий. Critical section защищает только
короткое копирование/скалярные статусы; NVS не вызывается под GUI-lock.
Один ключ содержит согласованную целую запись; атомарность при потере питания
требует физической приёмки. Между разными ключами общей транзакции нет.

Ticket глобален для backend и не сбрасывается при destroy приложения. GUI опрашивает
только актуальный ticket; старый commit не подтверждает новый snapshot. Worker не
сохраняет указателей на app/UI. Backend живёт до reset, ответы не вызывают callbacks.
Загрузка вне GUI-lock ждёт ранее принятые записи и завершается до первого рабочего
кадра. Destroy/new instance и reboot восстанавливают только READY/EMPTY, без звука.
Hide/suspend живого экземпляра сохраняют deadlines по прежнему контракту.

Ошибки записи: Couldn't save settings и Retry. RAM и сеанс продолжают работать;
Retry передаёт актуальные значения. Успех учитывается только после set+commit.
Повреждённый слот даёт EMPTY, неверная громкость — 40%; другие ключи не очищаются.
Новая неизвестная/oversized схема защищается от записи, показывается Newer settings
are read-only. Инициализация NVS никогда автоматически не вызывает erase.

Хост предоставляет полный optional backend load/submit/poll. Без него приложение
работает в RAM и показывает Settings won't be saved. kitchen_* не инициализирует
глобальный NVS хоста. ABI и lifetime описаны в INTEGRATION.md.

## Общая колонка и безопасные отступы

Сумма измеренных ширин шести preset labels с отступами и пятью зазорами по 8 px
задаёт общую ширину. Три roller с зазорами 12 px, их подписи и строка
значок/имя имеют ровно те же левый и правый края. Header row начинается на y=56
внутри панели, отдельно от заголовка; body — на y=140. Геометрия вычисляется
один раз при создании overlay, а не перестраивается на каждом tick.

Выбор значков занимает всю эту колонку без дополнительного текущего значка слева.
Закрытие — круглая область 48×48, отступ справа 2px, сверху 0px.
Close glyph выровнен по центру видимой формы через его bitmap metrics, а не
только по line box. Фон цвета слота с opacity 30%, нажатие 50%.
Основные кнопки карточек имеют мягкую pill-форму, полупрозрачную заливку и иконки
с text opacity 70%. Минимальные отступы кнопок от края — 16 px, максимальная
анимированная рамка — 11 px, поэтому остаётся минимум 5 px зазора. Для S4–S5
время использует поле высотой 44 px, статус/полоса подняты, чтобы кнопки 48×48
не пересекались с ними. Итоговый размер цифр подбирается существующими шрифтами.

## Геометрия текста имени и управления временем

Имя: textarea 56px, pad_top/bottom 10px, border 1px, Inter24 line-height 30px
в основном и placeholder представлении. Для строки остаётся 34px, поэтому
внутренний scroll-to-cursor LVGL не должен прокручивать текст вертикально.
При открытии y-scroll сбрасывается в 0; горизонтальная прокрутка длинного имени
остаётся. Проверка на панели нужна отдельно.

В normal overlay время занимает поле высотой 88px, статус расположен сразу под
ним, на y=92 и Inter Bold24. В PAUSED/DONE ±1min (или +1/Repeat) находятся
на y=140, progress — y=212. В READY/RUNNING без текста статуса время сдвинуто
на y=12, корректировки — y=120, progress — y=196: пустая строка не резервируется.
Кнопки корректировок остаются 56px/Inter24, progress 16px. Основные действия
на y=252 во всех состояниях — их вертикальное положение не прыгает.

Корректировки прижаты к левому/правому краям общей колонки, а не собраны узким
блоком в центре. Pause/Resume слева, Cancel timer справа; единственная Start/OK
по центру. Время и статус образуют верхний смысловой блок, корректировки вместе
с полосой — средний, запуск/остановка — отдельный нижний ряд. Размер overlay
и общая колонка сохранены; новые положения применяются только в обычном виде,
без перестроения барабанов, клавиатуры или черновиков редактора.

## Заголовки режимов overlay

Один title label Inter32 в левом верхнем углу панели (24,8) используется во всех
режимах. Отдельная подпись редактора между строкой icon/name и барабанами удалена.

| Контекст | Title |
| --- | --- |
| Первоначальная настройка | Set up timer |
| Обычное управление READY/RUNNING/PAUSED/DONE | Timer |
| Ввод имени | Timer name |
| Сохранённая длительность | Duration |
| Остаток RUNNING/PAUSED | Remaining time |
| Дополнительное время DONE | Add more time |

Title имени имеет приоритет, пока клавиатура открыта. Done/Cancel возвращают title
предыдущего режима с учётом актуального состояния. Выбор значков не вводит своего
title. Если RUNNING завершился в Remaining time, title становится Add more time,
черновик остаётся, защита первого Apply от случайного перезапуска сохраняется.

Start timer в первоначальной форме имеет LV_SYMBOL_PLAY рядом с label; ширина
вычисляется с учётом glyph и внутренних отступов. Play виден и при нулевом времени
на серой disabled кнопке; валидное время возвращает жёлтый фон. Title и кнопка
обновляются внутри существующего UI без пересоздания редактора и новых timers.

## Пропорциональная заполненность карточек

Положение карточек сетки не меняется. Внутри используются фактические w/h:
уровень шрифтов и значков выбирается по ширине, отступы, радиус, прогресс и
высота кнопки — от размеров карточки. Вертикальная раскладка считается от нижней
кнопки вверх: progress, status, time. Header выровнен по центру icon line box;
без значка имя начинается от основного inset. Длинные времена выбирают существующий
цифровой шрифт по доступной ширине, имя сокращается многоточием.

| Элемент | S1 392×512 | S2/S3 292×292 | S4–S5 292×208 |
| --- | --- | --- | --- |
| Кухонный glyph | 88px | 56px | 40px |
| Статус Inter700 | 36px | 24px | 18px |
| Label основной кнопки | 32px | 24px | 18px |
| Play/Pause/OK | 48px | 32px | 32px |
| Settings | 52px | 36px | 36px |
| Высота кнопки | 81px | 56px | 48px |
| Толщина progress | 23px | 13px | 10px |
| Основной inset | 21px | 16px | 16px |

Это ограниченное адаптивное масштабирование: минимальная touch area 48×48 и
читаемость малой карточки приоритетнее математически точного уменьшения всех
элементов. Цвета и формат записей остаются прежними; активны пять слотов.

Активная рамка усилена: DONE цикл 1000ms, RUNNING <60s — 1300ms, opacity48–255.
Базовая ширина зависит от ширины карточки (4–6px), активная плавно расширяется:
RUNNING base+1…base+7, DONE base+2…base+10, но не глубже inset−5. Поэтому до
кнопки остаётся минимум 5px даже на максимуме. На S1 DONE достигает16px, на
средних/маленьких11px. Внутреннее свечение остаётся слабым/узким, PAUSED не
пульсирует. Краевые invalidation strips учитывают масштабированный радиус, не
перерисовывая всю карточку каждый кадр. Фон под overlay остаётся замороженным.

## Статичный overlay и фиксированные позиции статуса

Анимация рамки применяется только к главной сетке. У раскрытой карточки рамка
всегда6px, opacity255, без внутреннего glow и без зависимости от RUNNING/DONE.
Она рисуется прежним inset callback, чтобы не сдвигать content origin.

Строка выбора значков отключает стандартный theme grow и transition нажатия.
При удержании появляется только оранжевая рамка2px в зарезервированном месте;

имеет оранжевую заливку, внешний первый тап внутри карточки сворачивает строку.

Обычный overlay сохраняет позиции вида без статуса: time y12, корректировки
y120, progress y196, нижние действия y252 (координаты относительно normal).
PAUSED показывается в свободном месте под видимыми цифрами, status y88,

progress y212, отдельный OK по центру на y252. Ширина OK учитывает checkmark,

Поле остаётся высотой56px; line39 + pad7 сверху/снизу + border1 помещаются

## Переход на раскладку B (07.11.2026)

S1–S3 сохраняют размеры и позиции. S4/S5 расширены до292px и стоят в тех же
колонках, что S2/S3, с gap12; высота208px сохранена. Нижний размерный уровень
определяется по высоте, поэтому glyph40, цифры36, status18 и кнопка48px
не становятся средними только из-за увеличенной ширины. Три уровня сохранены.

Модель содержит только S1–S5. При первом открытии NVS в процессе standalone
storage worker удаляет исключительно старый kitchen/slot6 и делает commit
до загрузки рабочего UI. На следующих стартах отсутствие ключа — нормальный
случай без записи. Это явное удаление по указанию владельца, включая неизвестную
схему этой удалённой записи; защита новых схем slot1–slot5 и volume сохраняется.
При ошибке удаления/commit выводится warning, повторная попытка при следующем
запуске; остальные настройки продолжают загружаться. Сбой питания допускает
повторение операции, весь namespace/раздел никогда автоматически не стирается.
После миграции возврат к старой шестислотовой версии создаст S6 пустым.
